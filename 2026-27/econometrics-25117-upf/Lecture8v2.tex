\begin{frame}{What we learned in the last lesson}
\begin{itemize}
    \item What if the marginal effect of $X$ on $Y$ is not constant? A linear regression is misspecified: the functional form is wrong.\\
    \item We can extend the multiple OLS framework to introduce non-linearities. The effect on $Y$ of a change in the independent variable(s) can be computed by evaluating the regression function at two values of the independent variable(s).\\
    \item A polynomial regression includes powers of $X$ as regressors. A quadratic regression includes $X$ and $X^2$, and a cubic regression includes $X$, $X^2$, and $X^3$.
    \item Small changes in logarithms can be interpreted as proportional or percentage changes in a variable. Regressions involving logarithms are used to estimate proportional changes and elasticities.
    \item The product of two variables is called an interaction term. When interaction terms are included as regressors, they allow the regression slope and/or intercept of one variable to depend on the value of another variable.
\end{itemize}
\end{frame}

\begin{frame}{Classic Pitfalls to Regression Analysis}
\begin{itemize}
    \item Let’s step back and take a broader look at regression. Is there a systematic way to assess (critique) regression studies? We know the strengths of multiple regression – but what are the pitfalls?\\[1em]
    \item We will list the most common reasons that multiple regression estimates, based on observational data, can result in biased estimates of the causal effect of interest.
\end{itemize}
\begin{exampleblock}{Internal validity}
The statistical inferences about causal effects are valid for the population being studied.
\end{exampleblock}
\begin{exampleblock}{External validity}
The statistical inferences can be generalized from the population and setting studied to other populations and settings, where the ``setting'' refers to the legal, policy, and physical environment and related salient features.
\end{exampleblock}

\end{frame}

\begin{frame}{External Validity}
Assessing threats to external validity requires detailed substantive knowledge and judgment on a case-by-case basis... How far can we generalize class size results from California?\\[1em]
\begin{itemize}
    \item[$\longrightarrow$] Differences in time (California in 1999 vs California in 2023? )\\[1em]
    \item[$\longrightarrow$] Differences in space (California in 1999 vs Catalonia in 1999?)\\[1em]
    \item[$\longrightarrow$] Differences in settings (Robust across different legal and institutional requirements/frameworks?)\\[1em]
\end{itemize}
Would you expect the magnitude and direction of the effects in the 1999 California schools sample to be the same for Catalonia in 2023?\\[1em]

A comparison of many related studies on the same topic is called a meta-analysis.
\end{frame}

\begin{frame}{Internal Validity}
Are the statistical inferences about causal effects valid for the population being studied?\\[1em]
Five threats to the internal validity of regression studies:
\begin{itemize}
    \item Omitted variable bias
    \item Wrong functional form
    \item Errors-in-variables bias
    \item Sample selection bias
    \item Simultaneous causality bias
\end{itemize}
\vspace{1em}
All of these imply that $\mathbb{E}(u_i\mid X_1, X_2, \dots, X_k)\neq 0$ (or that the conditional mean independence fails) – in which case O L S is biased and inconsistent!
\end{frame}

\begin{frame}{Omitted Variable Bias (revision)}
The bias in the OLS estimator that occurs as a result of an omitted factor, or variable, is called omitted variable bias. For omitted variable bias to occur, the omitted variable $Z$ must satisfy two conditions:
\begin{enumerate}
    \item $Z$ is a determinant of $Y$ (i.e. $Z$ is part of $u$); and
    \item $Z$ is correlated with the regressor $X$ (i.e., $corr(Z,X)\neq 0)$
\end{enumerate}

If the multiple regression includes control variables, then we need to ask whether there are omitted factors that are not adequately controlled for, that is, whether the error term is correlated with the variable of interest even after we have included the control variables.

\begin{frame}{Solutions to OVB}

\begin{itemize}
    \item If the omitted causal variable can be measured, include it as an additional regressor in multiple regression;\\[1em]
    \item If the omitted variable(s) cannot be measured or adequately controlled for, use instrumental variables regression ($Lecture~9$);\\[1em]
    \item Possibly, use panel data in which each entity (individual) is observed more than once ($Lecture~10$);\\[1em]
\end{itemize}
\end{frame}

\begin{frame}{Errors-in-variables}
So far we have assumed that $X$ is measured without error.\\[1em]

In reality, economic data often have measurement error
\begin{itemize}
    \item Data entry errors in administrative data
    \item Recollection errors in surveys (when did you start your current job?)
    \item Ambiguous questions (what was your income last year?)
    \item Intentionally false response problems with surveys (What is the current value of your financial assets? How often do you drink and drive?)
\end{itemize}
\vspace{1em}
Now consider $\tilde{X}$, the mis-measured version of X (which is the actually observed data) vs $X$, the true, unobserved value of your treatment...
\end{frame}

\begin{frame}{Errors-in-variables}
\small
\setlength{\abovedisplayskip}{4pt}
\setlength{\belowdisplayskip}{4pt}
For observation $i$, $X_i$ is the true, unobserved regressor and $\tilde{X}_i$ is the observed, mismeasured regressor. The measurement error is $v_i=\tilde{X}_i-X_i$, so $X_i-\tilde{X}_i=-v_i$ is the true minus recorded value.

\medskip
Start from the true model and rewrite $X_i$ using the observed regressor:
\[
    Y_i=\beta_0+\beta_1 X_i+u_i,
    \qquad X_i=\tilde{X}_i+(X_i-\tilde{X}_i).
\]
Substituting gives
\[
    Y_i=\beta_0+\beta_1\tilde{X}_i+\underbrace{\beta_1(X_i-\tilde{X}_i)+u_i}_{\tilde{u}_i}.
\]
The unobserved measurement discrepancy $X_i-\tilde{X}_i$ enters the regression error $\tilde{u}_i$. Therefore,
\[
    \operatorname{cov}(\tilde{X}_i,\tilde{u}_i)
    =\beta_1\operatorname{cov}(\tilde{X}_i,X_i-\tilde{X}_i)
    +\operatorname{cov}(\tilde{X}_i,u_i).
\]
Even if $\operatorname{cov}(\tilde{X}_i,u_i)=0$, the first term can be nonzero: the observed regressor is then correlated with the new error, biasing OLS.
\end{frame}

\begin{frame}{Classical Measurement Error}
The classical measurement error model assumes that $\tilde{X}_i=X_i+v_i$ where $v_i$ is is mean-zero random noise (e.g., white noise) with $\operatorname{Cov}(X_i,v_i)=0$ and $\operatorname{Cov}(u_i,v_i)=0$.\\[1em]

Under the classic measurement error model, $\hat{\beta}_1$ will be biased towards zero...\\[1em]

Intuitively: Take the true variable and add a very large amount of random noise. In the limit, $\tilde{X}_i$ will be completely unrelated to $Y_i$ so $\mathbb{E}(\hat{\beta}_1)$ is zero...\\[1em]

Before reaching this limit, the relationship between  $\tilde{X}_i$ and $Y_i$ will be toned down, biasing $\hat{\beta}_1$ towards zero.\\[1em]

\end{frame}

\begin{frame}{Covariance and Variance under Classical Measurement Error}
\small
Let $U_i$ be the true regression error and $V_i$ the measurement error. Then
$\tilde X_i=X_i+V_i$ and $\tilde U_i=U_i-\beta_1 V_i$.

\medskip
The true-model assumption $\mathbb{E}(U_i\mid X_i)=0$ implies $\operatorname{Cov}(X_i,U_i)=0$.
Classical measurement error gives $\operatorname{Cov}(X_i,V_i)=0$ and $\operatorname{Cov}(U_i,V_i)=0$.
\[
\begin{aligned}
\operatorname{Cov}(\tilde X_i,\tilde U_i)
  &= \operatorname{Cov}(X_i+V_i,U_i-\beta_1 V_i) \\
  &= \operatorname{Cov}(X_i+V_i,U_i)-\beta_1\operatorname{Cov}(X_i+V_i,V_i) \\
  &= \operatorname{Cov}(X_i,U_i)+\operatorname{Cov}(V_i,U_i)
     -\beta_1\bigl[\operatorname{Cov}(X_i,V_i)+\operatorname{Var}(V_i)\bigr] \\
  &= -\beta_1\operatorname{Var}(V_i)=-\beta_1\sigma_V^2.
\end{aligned}
\]
The observed regressor has variance
\[
\begin{aligned}
\operatorname{Var}(\tilde X_i)
  &= \operatorname{Var}(X_i+V_i) \\
  &= \operatorname{Var}(X_i)+2\operatorname{Cov}(X_i,V_i)+\operatorname{Var}(V_i) \\
  &= \sigma_X^2+\sigma_V^2.
\end{aligned}
\]
\end{frame}

\begin{frame}{OLS Probability Limit under Classical Measurement Error}
\small
\setlength{\abovedisplayskip}{4pt}
\setlength{\belowdisplayskip}{4pt}
Let $S_{A,B}$ be the sample covariance of $A$ and $B$, with bars denoting sample means.
\[
S_{A,B}=\frac{1}{n}\sum_{i=1}^n(A_i-\bar A)(B_i-\bar B)
       =\overline{AB}-\bar A\bar B.
\]
For OLS with an intercept, center $Y_i=\beta_0+\beta_1\tilde X_i+\tilde U_i$ to get
\[
Y_i-\bar Y=\beta_1(\tilde X_i-\overline{\tilde X})+(\tilde U_i-\overline{\tilde U}).
\]
Substitute this into the sample slope.
\[
\hat\beta_1
=\frac{S_{\tilde X,Y}}{S_{\tilde X,\tilde X}}
=\frac{\beta_1 S_{\tilde X,\tilde X}+S_{\tilde X,\tilde U}}{S_{\tilde X,\tilde X}}
=\beta_1+\frac{S_{\tilde X,\tilde U}}{S_{\tilde X,\tilde X}}.
\]
With i.i.d. observations and finite second moments, the law of large numbers gives
\[
S_{A,B}\xrightarrow{p}\mathbb{E}(A_i B_i)-\mathbb{E}(A_i)\mathbb{E}(B_i)=\operatorname{Cov}(A_i,B_i).
\]
Since $\operatorname{Var}(\tilde X_i)>0$, we can take the ratio of the limits.
\[
\hat\beta_1\xrightarrow{p}
\beta_1+\frac{\operatorname{Cov}(\tilde X_i,\tilde U_i)}{\operatorname{Var}(\tilde X_i)}
=\beta_1-\beta_1\frac{\sigma_V^2}{\sigma_X^2+\sigma_V^2}
=\beta_1\frac{\sigma_X^2}{\sigma_X^2+\sigma_V^2}.
\]
The probability limit moves toward zero as $\sigma_V^2$ grows with $\sigma_X^2$ fixed.
\end{frame}

\begin{frame}{Missing Data}
Data are often missing. Whether this biases a regression depends on \textbf{which observations remain in the sample}.
\begin{enumerate}
    \item Observations are missing completely at random (independently of $X$ and $u$).
    \item Missingness depends only on the observed regressors $X$.
    \item Missingness depends on $Y$ or on unobserved factors $u$, even after conditioning on $X$.
\end{enumerate}
\medskip
For a correctly specified model with $\mathbb{E}(u\mid X)=0$, cases 1 and 2 preserve the zero-conditional-mean assumption where data remain. We still need variation in $X$ to estimate the slope.
\medskip

\textbf{Case 1:} Your dog randomly eats 20 of 100 response sheets. The remaining 80 are still a random sample; losing observations reduces information.
\medskip

\textbf{Case 2:} Schools with a subsidized-meal share below 40\% are absent. Selection is based on $X$; the relationship can still be estimated over the observed range, but the sample does not establish its shape outside that range.
\medskip

\textbf{Case 3 can introduce sample selection bias.} The next slides show why, and why selection on $Y$ and selection on $u$ are related but distinct.
\end{frame}

\begin{frame}{Selection: Which Mean Must Be Zero?}
\small
\textbf{1. Define an indicator for whether an observation is available:}
\[
S_i=\begin{cases}1,&\text{observation $i$ is included in the regression},\\
0,&\text{observation $i$ is missing or excluded}.\end{cases}
\]
\textbf{2. Start with a valid model in the full population:}
\[
Y_i=\beta_0+\beta_1X_i+u_i,
\qquad \mathbb{E}(u_i\mid X_i)=0.
\]
OLS uses only observations with $S_i=1$. In that selected population,
\[
\mathbb{E}(Y_i\mid X_i,S_i=1)
=\beta_0+\beta_1X_i+\underbrace{\mathbb{E}(u_i\mid X_i,S_i=1)}_{\text{does selection change this mean?}}.
\]
\textbf{3. A common example for the next slides:}
\[
\boxed{Y_i=2+X_i+u_i,\quad X_i\in\{0,1,2\},\quad
u_i\sim\mathrm{Uniform}[-2,2],\quad u_i\text{ independent of }X_i.}
\]
Each value of $X_i$ has probability $1/3$. At every $X_i$, errors are evenly spread from $-2$ to $2$, so their mean is zero and $\mathbb{E}(Y_i\mid X_i)=2+X_i$.
\medskip

\textbf{Interpretation:} $X$ is an observed characteristic and $u$ collects unobserved factors that raise or lower $Y$ relative to its predicted value.
\end{frame}

\begin{frame}{Selection Only on $X$: Keep $X_i\geq1$}
\small
Use $Y_i=2+X_i+U_i$ with $U_i$ independent of $X_i$ and uniform on $[-2,2]$.
\medskip

\textbf{1. Selection rule:} $S_i=1$ if $X_i\geq1$; otherwise $S_i=0$.
\begin{center}
\begin{tabular}{cclc}
\hline
$X_i$ & Included? & Errors among included observations & Mean error\\
\hline
0 & No & No observations retained & Not defined\\
1 & Yes & Entire interval $[-2,2]$ & 0\\
2 & Yes & Entire interval $[-2,2]$ & 0\\
\hline
\end{tabular}
\end{center}
\textbf{2. Why the mean error stays zero.}
At $x=1$ or $2$, the rule includes every observation with $X_i=x$, so
\[
\{X_i=x, S_i=1\}=\{X_i=x\}\text{ for }x\in\{1,2\}.
\]
The conditioning events are the same. Independence of $U_i$ and $X_i$ then gives
\[
\mathbb{E}(U_i\mid X_i=x,S_i=1)
=\mathbb{E}(U_i\mid X_i=x)=\mathbb{E}(U_i)=0.
\]
\textbf{3. The regression relationship is preserved:}
\[
\mathbb{E}(Y_i\mid X_i=x,S_i=1)=2+x\text{ for }x\in\{1,2\}.
\]
Both retained values identify the slope of 1.
\end{frame}

\begin{frame}{Selection Only on $Y$: Keep $Y_i\geq3$}
\small
\setlength{\abovedisplayskip}{3pt}
\setlength{\belowdisplayskip}{3pt}
\textbf{1. Rewrite the outcome-based rule using $Y_i=2+X_i+U_i$:}
\[
S_i=1\ \Longleftrightarrow\ Y_i\geq3
\ \Longleftrightarrow\ 2+X_i+U_i\geq3
\ \Longleftrightarrow\ \boxed{U_i\geq1-X_i.}
\]
\textbf{2. Compute the mean of the retained errors.}
At $X_i=x$, the uniform error is restricted to $[1-x,2]$.
The interval has length $2-(1-x)=1+x$, so the conditional density on it is $1/(1+x)$.
\[
\begin{aligned}
\mathbb{E}(U_i\mid X_i=x,S_i=1)
&=\int_{1-x}^{2}\frac{u}{1+x}\,du
=\frac{2^2-(1-x)^2}{2(1+x)}\\
&=\frac{[2-(1-x)][2+(1-x)]}{2(1+x)}
=\frac{3-x}{2}.
\end{aligned}
\]
\begin{center}
\begin{tabular}{ccccc}
\hline
$X_i$ & Retained $U_i$ & Mean $U_i$ & Full-sample mean $Y_i$ & Selected mean $Y_i$\\
\hline
0 & $[1,2]$ & 1.5 & 2 & 3.5\\
1 & $[0,2]$ & 1 & 3 & 4\\
2 & $[-1,2]$ & 0.5 & 4 & 4.5\\
\hline
\end{tabular}
\end{center}
\textbf{3. Substitute the new mean error into the regression:}
\[
\mathbb{E}(Y_i\mid X_i=x,S_i=1)
=2+x+\frac{3-x}{2}=\boxed{3.5+0.5x}.
\]
Page 19 explains how this rule changes both who enters the sample and the estimated slope.
\end{frame}

\begin{frame}{Who Is Selected and Why the Slope Falls}
\small
\textbf{Larger $X_i$ makes selection more likely.}
The rule $Y_i\geq3$ requires $U_i\geq1-x$ at $X_i=x$. As $x$ rises, the cutoff falls and more of the uniform error distribution is retained.
\[
\Pr(S_i=1\mid X_i=x)=\frac{2-(1-x)}{4}=\frac{1+x}{4}.
\]
The selection probabilities at $x=0,1,2$ are $1/4$, $1/2$ and $3/4$, respectively.

\medskip
\textbf{Selection raises mean $Y_i$ more at low $X_i$.}
At $x=0$, the cutoff $U_i\geq1$ raises mean $Y_i$ from $2$ to $3.5$.
At $x=2$, the cutoff $U_i\geq-1$ raises mean $Y_i$ from $4$ to $4.5$.
The gap in mean outcomes shrinks from $2$ to $1$ over the same two-unit change in $x$.
\[
\begin{aligned}
\text{Full-population slope} &= \frac{4-2}{2-0}=1,\\
\text{Selected-population slope} &= \frac{4.5-3.5}{2-0}=0.5.
\end{aligned}
\]
\end{frame}

\begin{frame}{Sample Selection Bias}

\begin{block}{Sample selection bias}
Bias that arises when a selection process \textbf{a)} influences the availability of data, and  \textbf{b)} is related to the dependent variable beyond depending on the regressors.
\end{block}
\vspace{1em}
\textbf{Fictuous Simple Example:} you want to estimate the average males' height in Barcelona. To collect your data, you go to the Palau Blaugrana and record the heights of the basketball team. Formally, you have sampled individuals in a way that is related to the outcome $Y$ (height), which results in bias.

\vspace{1em}

\textbf{Real Example:} In 1936, the Literary Gazette published a poll predicting that presidential candidate Landon would win by a landslide against Roosevelt. The opposite happened: Roosevelt won with 60.8\% of the votes. It turned out that the Literary Gazette had sampled phone records from automobile registration files. In 1936, people owning a car and a telephone were richer, and more likely Republicans... supporting Landon.

\vspace{1em}

\textbf{Solution:} Avoid it in the first place. If you cannot, some methods for estimating models with sample selection exist (not now,  a bit discussed in $Lecture~11$).
\end{frame}

\begin{frame}{Simultaneity Bias}
\begin{block}{Simultaneity Bias}
Also called simultaneous equations bias. It arises in a regression of $Y$ on $X$ when, in addition to the causal link of interest from $X$ to $Y$, there is a causal link from $Y$ to $X$. This reverse causality makes $X$ correlated with the error term in the population regression of interest.
\end{block}
\vspace{1em}
\textbf{California Example:} The share of subsidised meals affects schools test scores. But schools with higher test scores might be allocated more resources, allowing them to subsidise more meals.

\vspace{1em}

Consider the following system of simultaneous equations:
\begin{eqnarray*}
    &Y_i &= \beta_0 + \beta_1 X_i + u_i\\
    &X_i &= \gamma_0 + \gamma_1 Y_i + v_i
\end{eqnarray*}
$X_i$ is a function of $u_i$, the unexplained variation of $Y_i$.

\vspace{1em}

\textbf{Solution:} Mostly RCT or IV methods ($Lecture~9$).
\end{frame}


\begin{frame}
\frametitle{Simultaneity: Why Is $X_i$ Correlated with $u_i$?}
\small
\setlength{\abovedisplayskip}{4pt}
\setlength{\belowdisplayskip}{4pt}
\textbf{1. Start with the two equations on the previous slide:}
\[
Y_i=\beta_0+\beta_1X_i+u_i,
\qquad X_i=\gamma_0+\gamma_1Y_i+v_i.
\]
To isolate reverse causality, assume $\operatorname{Cov}(u_i,v_i)=0$, $\operatorname{Var}(u_i)>0$, and $1-\gamma_1\beta_1\neq0$.
\medskip

\textbf{2. Substitute the equation for $Y_i$ into the equation for $X_i$:}
\[
X_i=\gamma_0+\gamma_1(\beta_0+\beta_1X_i+u_i)+v_i
\quad\Rightarrow\quad
(1-\gamma_1\beta_1)X_i=\gamma_0+\gamma_1\beta_0+\gamma_1u_i+v_i.
\]
\textbf{3. Solve for $X_i$: the outcome error now appears inside the regressor.}
\[
X_i=\frac{\gamma_0+\gamma_1\beta_0}{1-\gamma_1\beta_1}
+\underbrace{\frac{\gamma_1}{1-\gamma_1\beta_1}u_i}_{\text{reverse-causality channel}}
+\frac{1}{1-\gamma_1\beta_1}v_i.
\]
\textbf{4. Take the covariance with $u_i$ (the constant contributes zero):}
\[
\operatorname{Cov}(X_i,u_i)
=\frac{\gamma_1\operatorname{Var}(u_i)+\operatorname{Cov}(v_i,u_i)}{1-\gamma_1\beta_1}
=\boxed{\frac{\gamma_1\operatorname{Var}(u_i)}{1-\gamma_1\beta_1}\neq0\quad\text{if }\gamma_1\neq0.}
\]
\textbf{Intuition:} a shock $u_i$ changes $Y_i$; because $Y_i$ feeds back into $X_i$, the regressor responds to that same shock. Thus $\mathbb{E}(u_i\mid X_i)=0$ cannot hold, and OLS confounds the causal effect with feedback. If $\gamma_1=0$, this channel disappears.
\end{frame}

\begin{frame}{Internal Validity Checklist for Multiple Variables Regressions}
When assessing a causal estimate from multiple regression, check for these five threats.
\begin{enumerate}
    \item Omitted variables
    \item Functional form misspecification
    \item Errors in variables (measurement error in the regressors)
    \item Sample selection
    \item Simultaneous causality
\end{enumerate}
\end{frame}

\begin{frame}{What about prediction?}
Prediction and estimation of causal effects are quite different objectives.\\[1em]
For prediction:
\begin{enumerate}
    \item The data used to estimate the prediction model must be \textit{from the same distribution} as the out-of-sample observation for which the prediction is made. This is an external validity requirement for a prediction model.
    \item The predictors should be ones \textit{that substantially contribute to explaining the variation in $Y$}. They do not need to have direct causal interpretations, and the regression coefficients in general need not estimate causal effects.
    \item The estimator must be one that produces \textit{reliable out-of-sample predictions}. When the number of regressors (predictors) is small relative to the number of observations, OLS can be used. But when the number of predictors is large, there are better estimators than OLS -- ones developed specially for the prediction problem (Big Data techniques, beyond the scope of this course).
\end{enumerate}
\end{frame}
